# Loan Default & Credit Risk Analysis

## Project Title
Loan Default & Credit Risk Analysis

## Objective
Analyze customer demographics, income, credit score, loan amount, repayment/default history, debt-to-income ratio, and other lending attributes to identify patterns associated with loan default and support credit-risk monitoring.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI Desktop
- Power Query
- DAX

## Dataset
The cleaned dataset contains 2,000 loan records and 28 columns after data cleaning and feature engineering.

Key fields include:
Customer_ID, Gender, Age, Education, Employment_Status, Annual_Income, Credit_Score, Loan_ID, Loan_Type, Loan_Amount, Interest_Rate, Monthly_Installment, Debt_to_Income_Ratio, Previous_Defaults, Region, Default_Status, Credit_Score_Group, Income_Group, and DTI_Group.

## Data Cleaning
- Removed duplicate records.
- Filled missing Annual_Income, Credit_Score, and Employment_Years using median values.
- Filled missing Property_Ownership using the mode.
- Trimmed text fields.
- Checked numerical outliers using the IQR method.
- Created Default_Flag, Credit_Score_Group, Income_Group, and DTI_Group.

## Key Results
- Total customers: 2,000

- Defaulted loans: 224
- Non-defaulted loans: 1,776
- Overall default rate: 11.20%
- Average credit score: 691.98
- Average annual income: 745,402.55
- Average loan amount: 1,337,582.50
- Average DTI: 47.18%

## Key Insights
1. Overall default rate is 11.20%.
2. Business loans have the highest default rate at 17.11%.
3. South has the highest regional default rate at 13.29%.
4. Unemployed borrowers have the highest employment-status default rate at 26.85%.
5. Defaulted borrowers have an average credit score of 654.36, compared with 696.73 for non-defaulted borrowers.
6. Defaulted borrowers have an average DTI of 63.43%, compared with 45.14% for non-defaulted borrowers.
7. Previous defaults show a strong association with current default risk; the highest observed group is 3 previous defaults with a 63.64% current default rate.
8. The highest-risk sufficiently sized credit/income segment is Poor credit / Low Income with a 75.00% default rate.
9. Defaulted borrowers have average loan amount 1,621,553.57, versus 1,301,766.33 for non-defaulted borrowers.
10. Credit-risk monitoring should prioritize credit score, DTI, previous defaults, income, employment status, and loan type.

## Power BI Measures
```DAX
Total Customers =
DISTINCTCOUNT(Loan_Credit_Risk_Cleaned[Customer_ID])

Total Loans =
DISTINCTCOUNT(Loan_Credit_Risk_Cleaned[Loan_ID])

Defaulted Loans =
CALCULATE(
    DISTINCTCOUNT(Loan_Credit_Risk_Cleaned[Loan_ID]),
    Loan_Credit_Risk_Cleaned[Default_Status] = "Defaulted"
)

Non-Defaulted Loans =
CALCULATE(
    DISTINCTCOUNT(Loan_Credit_Risk_Cleaned[Loan_ID]),
    Loan_Credit_Risk_Cleaned[Default_Status] = "Non-Defaulted"
)

Default Rate % =
DIVIDE([Defaulted Loans], [Total Loans], 0)

Average Loan Amount =
AVERAGE(Loan_Credit_Risk_Cleaned[Loan_Amount])

Average Credit Score =
AVERAGE(Loan_Credit_Risk_Cleaned[Credit_Score])

Average Annual Income =
AVERAGE(Loan_Credit_Risk_Cleaned[Annual_Income])
```
